# Parakeet V3

## Installation

```cmd
uv venv .venv --python 3.13

call .venv\Scripts\activate.bat

uv pip install onnx-asr
uv pip install onnxruntime
uv pip install huggingface_hub
```

## Download Model

```cmd
git clone https://huggingface.co/istupakov/parakeet-tdt-0.6b-v3-onnx
```
